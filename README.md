# Node.js Docker and Compose

Backend learning project created during the Yandex Practicum Professional Training course:

**"Backend with Node.js for Frontend Developers"**

This project demonstrates working with Docker and Docker Compose for setting up and running a Node.js backend application in a containerized environment.

---

## 📌 About The Project

The goal of this project was to learn how to containerize backend applications and create a reproducible development environment.

The project focuses on:

- creating Docker containers for Node.js applications;
- working with Docker images and containers;
- configuring services with Docker Compose;
- setting up application environments;
- understanding container-based development workflows.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Docker
- Docker Compose

### Installation

Clone the repository:

```bash
git clone https://github.com/OlgaZaglavnova/nodejs-docker-and-compose.git
```

Navigate to the project folder:

```bash
cd nodejs-docker-and-compose
```

Install dependencies:

```bash
npm install
```

---

## Run with Docker Compose

Build and start containers:

```bash
docker compose up --build
```

Stop containers:

```bash
docker compose down
```
